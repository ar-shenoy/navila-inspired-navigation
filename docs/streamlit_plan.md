# NaVILA-Lite Streamlit Plan

## Goal
A single, robust, interactive demo that any user can open and try.

## Core Features
- High-level language planner (mid-level commands)
- Low-level controller with reactive (RL-inspired) obstacle avoidance
- Multiple environments
- Real-time 2.5D visualization
- Command history and metrics

## How to run locally
```bash
pip install -r requirements_app.txt
streamlit run app.py
```

## Deployment target
Hugging Face Spaces (CPU Basic) – free and public link.
